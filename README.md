# Megh-Mallar 🌦️

**A Python-based CLI Weather Application**

Megh-Mallar is a command-line weather application built with Python that fetches weather information directly from your terminal.

## Features

- Fetch weather information from the command line.
- Simple and lightweight CLI experience.
- Built with Python.

## Tech Stack
